# UbiBatch

**Automatización de tareas por lotes para la administración de dispositivos Ubiquiti.**

UbiBatch es una herramienta orientada a simplificar tareas repetitivas sobre múltiples equipos Ubiquiti. Su enfoque es llevar operaciones habituales de soporte y mantenimiento a un flujo de trabajo más ágil, evitando tener que realizar cada acción de forma manual en cada dispositivo.

## ¿Qué resuelve?

Cuando se administra infraestructura inalámbrica, determinadas tareas deben repetirse sobre varios equipos. UbiBatch busca centralizar y agilizar ese trabajo mediante scripts de automatización.

Entre los usos contemplados por el proyecto se encuentran:

- **Operaciones sobre múltiples dispositivos:** ejecución de tareas de administración de forma organizada.
- **Monitoreo:** apoyo en la consulta del estado de los equipos.
- **Backups:** automatización de tareas relacionadas con copias de seguridad.
- **Compliance:** asistencia en la gestión/liberación del estado de compliance.

## Tecnologías

- Python
- Automatización mediante scripts
- Comunicación remota con dispositivos Ubiquiti

## Instalación

```bash
git clone https://github.com/EmmaBia93/UbiBatch.git
cd UbiBatch
```

Consultá los archivos del proyecto para identificar las dependencias y los parámetros de configuración necesarios antes de ejecutarlo.

> **Importante:** ejecutá las operaciones únicamente sobre equipos que tengas autorización para administrar. Verificá el alcance de cada acción antes de aplicarla en un entorno productivo.
